
# Clínica Fácil

## Sobre o projeto

O Clínica Fácil é um sistema web desenvolvido para gerenciar pacientes e consultas de uma clínica fictícia.

O projeto foi desenvolvido individualmente para o Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas do SENAC.

## Funcionalidades

- Cadastro de pacientes
- Listagem, edição e exclusão de pacientes
- Busca de pacientes pelo nome
- Agendamento de consultas
- Edição e exclusão de consultas
- API de pacientes em JSON
- Interface responsiva

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- GitHub
- Render

## Banco de dados

O sistema possui duas tabelas relacionadas:
pacientes e consultas.

Um paciente pode possuir várias consultas.

## Como executar

1. Instale as dependências com pip install -r requirements.txt
2. Execute python database.py
3. Execute python -m flask --app app run --port 5001
4. Acesse http://127.0.0.1:5001

## Aviso

Este sistema é um projeto educacional.
Utilize apenas dados fictícios.
